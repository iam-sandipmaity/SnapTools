## Key Metrics to Track

### Google Search Console
- **Impressions**: How many times your site appears in search
- **Clicks**: How many people click through to your site
- **CTR (Click-Through Rate)**: Impressions vs Clicks ratio
- **Average Position**: Where you rank on average
- **Top Keywords**: Which keywords bring most traffic

Target Goals:
- Impressions: +20% month-over-month
- CTR: Above 3% average (aim for 5%+)
- Average Position: Move from page 2-3 to page 1 (top 10)

### Google Analytics
- **Organic Traffic**: Visitors from search engines
- **Bounce Rate**: Keep below 50%
- **Session Duration**: Aim for 2+ minutes
- **Pages Per Session**: Aim for 2.5+
- **Top Landing Pages**: Identify winners

Target Goals:
- Organic Traffic: +30% quarter-over-quarter
- Bounce Rate: <45%
- Tool Usage: Track with events

## On-Page SEO Checklist (For New Pages)

When adding new tool pages, ensure:
- [ ] Unique H1 tag with primary keyword
- [ ] Meta title (50-60 characters) with keyword
- [ ] Meta description (150-160 characters) with CTA
- [ ] H2 and H3 subheadings with related keywords
- [ ] 300+ words of unique content
- [ ] Alt text for all images
- [ ] Internal links to 3-5 related pages
- [ ] Schema markup (WebApplication, HowTo, or BreadcrumbList)
- [ ] Mobile-friendly design
- [ ] Fast load time (<3 seconds)
- [ ] Clear CTA (call-to-action)
- [ ] Social sharing buttons

## Red Flags to Watch For

### Search Console Warnings
- ❌ Coverage errors increasing
- ❌ Mobile usability issues
- ❌ Core Web Vitals failing
- ❌ Manual actions/penalties
- ❌ Security issues

### Analytics Red Flags
- ❌ Sudden traffic drop (>20%)
- ❌ Increasing bounce rate
- ❌ Declining average session duration
- ❌ Fewer pages per session

### Technical Issues
- ❌ Site downtime
- ❌ Slow page load (>3 seconds)
- ❌ Broken links (404 errors)
- ❌ Duplicate content
- ❌ Missing alt tags on images

## Emergency Troubleshooting

### Traffic Suddenly Dropped?
1. Check Google Search Console for manual actions
2. Verify site is not down
3. Check for algorithm updates (Google updates)
4. Review recent changes to site
5. Check for technical issues (robots.txt, noindex tags)

### Not Ranking Despite Efforts?
1. Check keyword difficulty (may be too competitive)
2. Analyze top-ranking competitors
3. Increase content quality and depth
4. Build more backlinks
5. Improve user experience metrics

### Pages Not Being Indexed?
1. Submit sitemap in Search Console
2. Request indexing for important pages
3. Check robots.txt isn't blocking
4. Ensure pages are linked from other pages
5. Add more internal links to the page
