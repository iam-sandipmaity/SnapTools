## Reporting a Vulnerability

We take the security of SnapTools very seriously. If you have discovered or suspect a security vulnerability, please follow the procedure below to report it to us.

### How to Report

Please **DO NOT** create a public GitHub issue for security vulnerabilities. Instead, please report them privately by emailing social.sandipmaity@gmail.com.

In your email, please provide:

*   A detailed description of the vulnerability.
*   Steps to reproduce the vulnerability (a proof-of-concept script or a detailed explanation).
*   Any potential impact of the vulnerability.

### What Happens Next?

1.  **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
2.  **Investigation:** We will investigate the reported vulnerability and may ask for further information.
3.  **Resolution:** If a vulnerability is confirmed, we will work on a fix and release a security update.
4.  **Disclosure:** Once the fix is released, we will publicly disclose the vulnerability and credit you for the discovery (if you wish).

### Responsible Disclosure

We ask that you follow the principles of responsible disclosure:

*   Please give us reasonable time to investigate and fix the vulnerability before making it public.
*   Do not exploit the vulnerability to access or modify data that does not belong to you.
*   Do not perform denial-of-service attacks or other disruptive actions.

Thank you for helping keep SnapTools secure!
