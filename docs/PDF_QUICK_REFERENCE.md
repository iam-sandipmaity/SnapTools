# PDF Viewer - Quick Reference Guide

## 🚀 Quick Start

### Basic Operations
1. **Upload PDF** → Browse button or drag-and-drop
2. **Navigate** → Arrow keys or navigation buttons  
3. **Zoom** → +/- keys or zoom buttons
4. **Rotate** → R key or rotate button
5. **View Metadata** → Info button (ℹ️)
6. **Extract Text** → Document icon (📝)
7. **Remove Password** → Shield icon (🛡️) → Remove Password Protection

## 🔑 Keyboard Shortcuts

### Single Page Mode
| Key | Action |
|-----|--------|
| `←` or `↑` | Previous page |
| `→` or `↓` | Next page |
| `Home` | First page |
| `End` | Last page |
| `+` | Zoom in |
| `-` | Zoom out |
| `R` | Rotate 90° |

### Scroll Mode
| Key | Action |
|-----|--------|
| `↑` / `↓` | Scroll up/down |
| `PgUp` / `PgDn` | Page up/down |
| `Home` / `End` | Top/Bottom |
| `+` / `-` | Zoom in/out |
| `R` | Rotate 90° |

## 🔒 Password-Protected PDFs

### View Encrypted PDF
1. Upload encrypted PDF
2. Enter password when prompted
3. View and navigate normally

### Remove Password Protection
1. Upload encrypted PDF and unlock it
2. Click shield icon (🛡️)
3. Select "Remove Password Protection"
4. Click "Export PDF"
5. Download unencrypted version

### Add Password Protection (Experimental)
1. Upload any PDF
2. Click shield icon (🛡️)
3. Select "Add Password Protection"
4. Enter password
5. Click "Export PDF"
6. **Note**: May not work with all PDFs

## 🐛 Troubleshooting

### PDF Won't Load
- ✅ Verify file is a valid PDF
- ✅ Check if encrypted (enter password)
- ✅ Try refreshing the page

### Text Extraction Shows Nothing
- ℹ️ Some PDFs are image-based (need OCR)
- ℹ️ Check if PDF has selectable text

### Encryption Failed
- ⚠️ Encryption may not work with all PDFs
- ✅ Decryption (password removal) is more reliable
- ✅ Try with a simpler PDF
