## [0.1.0] - 2025-12-25

### 🎉 Initial Public Release

This is the first public release of **SnapTools**, marking a stable and usable foundation.

### ✨ Added
- Initial release of SnapTools web application
- Modular tool-based architecture
- PDF utilities (view, merge, split, compress, extract pages)
- Image tools (resize, convert, compress, Base64 encode/decode)
- QR code and barcode generation tools
- Text utilities (case conversion, formatting, word count)
- Encoding and decoding utilities (URL, HTML, Base64)
- Unit and number system converters
- Responsive, modern UI design
- Smooth animations using Framer Motion

### ⚙️ Technical
- Built with Vite + React + TypeScript
- Fully client-side processing (no file uploads)
- Lazy-loaded heavy libraries (PDF, crypto, QR, image processing)
- Optimized production build and chunking
- Stable React build pipeline for production environments

### 🔐 Privacy
- No server-side file handling
- No data storage
- All processing happens locally in the browser

### 🛠️ Fixed
- Resolved production-only React runtime crash
- Stabilized build configuration for deployment
- Cleaned up dependency and bundling issues
