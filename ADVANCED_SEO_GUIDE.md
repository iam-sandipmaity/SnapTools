### 3. **5 Structured Data Schemas**

#### ① SoftwareApplication Schema
```json
{
  "@type": "SoftwareApplication",
  "name": "Image Compressor",
  "aggregateRating": {
    "ratingValue": "4.8",
    "ratingCount": "1234"
  },
  "offers": {
    "price": "0",
    "priceCurrency": "USD"
  }
}
```
**Benefit:** Shows star ratings in search results

#### ② FAQ Schema
```json
{
  "@type": "FAQPage",
  "mainEntity": [
    {
      "name": "What is Image Compressor?",
      "acceptedAnswer": "..."
    },
    {
      "name": "Is Image Compressor free?",
      "acceptedAnswer": "Yes, completely free..."
    }
  ]
}
```
**Benefit:** Appears in Google's "People Also Ask" section

#### ③ HowTo Schema
```json
{
  "@type": "HowTo",
  "name": "How to use Image Compressor",
  "step": [
    { "name": "Open the tool", "position": 1 },
    { "name": "Input your data", "position": 2 },
    { "name": "Process", "position": 3 },
    { "name": "Get results", "position": 4 }
  ]
}
```
**Benefit:** Shows step-by-step instructions in rich results

#### ④ Breadcrumb Schema
```json
{
  "@type": "BreadcrumbList",
  "itemListElement": [
    "Home > Tools > Image Tools > Image Compressor"
  ]
}
```
**Benefit:** Better navigation in search results

#### ⑤ WebPage Schema
**Benefit:** Additional context for search engines
