## 🚦 Getting Started

### Prerequisites
- Node.js (v18.x or higher)
- Git

### Installation

1. **Clone the Repository**
```bash
git clone https://github.com/iam-sandipmaity/SnapTools.git
cd SnapTools
```

2. **Initialize Environment**
```bash
npm install
```

3. **Launch Discovery Server**
```bash
npm run dev
```

The workstation will be available at `http://localhost:5173`
